# SpecWave 格式契约

> 本文档定义 Skills 生成内容与 UI 解析的格式约定。修改模板或角色定义时，必须遵守本契约。

## 任务文档格式（03-任务.md）

### 任务行格式

```
- [ ] T-xxx：任务标题
```

- 必须以 `- [ ]` 或 `- [x]` 开头
- 任务编号格式：`T-xxx`（三位数字）
- 冒号使用中文全角 `：`

### 关联字段格式

```
  - 关联需求：REQ-001, AC-001, AC-002
```

- 字段名：`关联需求`（中文）
- 冒号：中文 `：` 或英文 `:`
- 引用格式：`REQ-xxx` 或 `AC-xxx`（xxx 为三位数字）
- 多个引用用逗号分隔（中文 `，` 或英文 `,`）

### UI 解析正则

```javascript
// 关联引用解析
/关联需求[：:]\s*(.+)$/m

// 引用格式验证
/^(REQ|AC)-\d{3}$/
```

## 需求文档格式（01-需求.md）

### 需求条目格式

```markdown
### REQ-001 需求标题

需求描述...

- **操作**：用户操作
- **预期**：预期结果
```

- 必须以 `### REQ-xxx` 开头（三级标题）
- 标题与编号之间有空格

### 验收口径格式

```markdown
- **AC-001**：操作步骤 → 预期结果
```

- 必须以 `- **AC-xxx**：` 开头
- 冒号后直接跟内容

### UI 解析正则

```javascript
// REQ 段落定位
/^###\s+REQ-(\d{3})\b/

// AC 行定位
/^-\s+\*\*AC-(\d{3})\*\*[：:]/
```

## 修改规范

1. **修改模板前**：先检查本契约中的格式定义
2. **修改后验证**：确保生成内容能被 UI 正则正确解析
3. **同步更新**：如需修改格式，必须同时更新本契约和 UI 解析代码

## 契约引用

在以下文件中需要遵守本契约：

| 文件 | 检查点 |
|------|--------|
| `需求分析师.md` | 任务格式示例包含 `关联需求：REQ-xxx, AC-xxx` |
| `开发执行者.md` | 任务状态更新规范 |
| `03-任务.md` 模板 | 占位符 `关联需求：REQ-001, AC-001` |
| `01-需求.md` 模板 | REQ-xxx 使用 `### REQ-xxx` 格式 |
| `01-需求.md` 模板 | AC-xxx 使用 `- **AC-xxx**：` 格式 |
| `AGENTS.md.template` | 包含执行阶段更新任务的硬规则 |
