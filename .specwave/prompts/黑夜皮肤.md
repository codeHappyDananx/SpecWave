# 黑夜皮肤需求

## 诉求

实现完整的深色/浅色主题切换功能。目前的皮肤切换只是换主色调（blue/purple/green/amber），没有真正的深色模式。

## 期望效果

1. 点击皮肤按钮可以在「白天模式」和「黑夜模式」之间切换
2. 黑夜模式下整个软件的背景、文字、边框等颜色都要变成深色系
3. 主色调（blue/purple/green/amber）在两种模式下都能正常工作
4. 用户的模式偏好要持久化到 localStorage
5. 终端区域已经是深色，黑夜模式下保持不变即可

## 当前实现分析

### CSS 变量体系（packages/ui-next/src/styles.css）

```css
:root {
  --sw-bg: #ffffff;        /* 背景色 */
  --sw-fg: #111827;        /* 前景色/文字 */
  --sw-muted: #f3f4f6;     /* 次要背景 */
  --sw-border: #e5e7eb;    /* 边框 */
  --sw-scrollbar-thumb: rgba(17, 24, 39, 0.18);
  /* ... 其他变量 */
}
```

### 皮肤切换逻辑（apps/desktop/src/renderer/src/store.ts）

```typescript
case 'THEME_TOGGLE': {
  const skins = ['blue', 'purple', 'green', 'amber'];
  // 只切换主色调，没有深色模式
}
```

### 皮肤应用（packages/ui-next/src/shell/SpecWaveApp.tsx）

```tsx
<div data-skin={vm.ui.skin}>
```

## 建议实现方案

1. 在 `styles.css` 中添加 `[data-theme="dark"]` 选择器，覆盖所有 `--sw-*` 变量为深色值
2. 在 `UIViewModel` 中添加 `theme: 'light' | 'dark'` 字段
3. 修改 `THEME_TOGGLE` 逻辑，切换 `theme` 而非 `skin`
4. 在根元素上同时应用 `data-skin` 和 `data-theme`
5. 可以考虑添加一个单独的按钮切换主色调，或者长按切换主色调
