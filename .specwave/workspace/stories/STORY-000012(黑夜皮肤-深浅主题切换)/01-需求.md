# 需求文档

> Story：STORY-000012(黑夜皮肤-深浅主题切换)  
> 状态：已确认

## 你最终会看到什么

1) 顶部栏现有“皮肤”按钮：点击在「白天模式 / 黑夜模式」之间切换。  
2) 黑夜模式下，工作区（顶部栏/左栏/中栏/右栏/底部栏）的背景、文字、边框、滚动条都切换为深色系。  
3) 主色皮肤（blue/purple/green/amber）在白天/黑夜两种模式下都能正常生效。  
4) 主题偏好会写入 `localStorage`，重启/刷新后自动恢复。  
5) 终端区域本来就是深色：黑夜模式下保持现状，不需要额外变更。

## 需求列表

### REQ-001 顶部栏主题切换（白天/黑夜）

- **操作**：点击顶部栏的“皮肤”按钮。
- **预期**：主题在 `light` 与 `dark` 间切换，工作区整体观感随之变化。

### REQ-002 黑夜模式覆盖工作区视觉要素

- **操作**：切到黑夜模式，观察工作区各区域（顶部栏/左/中/右/底部）。
- **预期**：背景、文字、边框、次级背景、滚动条等都切换为深色系，阅读对比度正常。

### REQ-003 主色皮肤在两种主题下都可用

- **操作**：切换主色皮肤（blue/purple/green/amber），再分别在白天/黑夜模式下观察 UI 的主色点位（例如 focus/active/强调色）。
- **预期**：主色皮肤在两种主题下都能生效，不出现“深色模式下主色失效”的情况。

### REQ-004 主题偏好持久化

- **操作**：切到黑夜模式后刷新窗口/重启应用。
- **预期**：主题偏好自动恢复到上次选择；写入 key 为 `specwave_theme`。

### REQ-005 终端区域保持现状

- **操作**：切到黑夜模式后打开/切换右侧终端面板，观察终端区域背景与配色。
- **预期**：终端区域继续沿用当前深色外观与对比度，不需要跟随全局再做“二次变暗/变亮”。

### REQ-006 白天模式保持现状

- **操作**：保持白天模式，观察工作区整体观感（背景、边框、文本、按钮）。
- **预期**：白天模式视觉与当前版本一致（不出现“突然变灰/变亮/字看不清”的变化）。

## 验收口径

- **AC-001**：点击顶部栏“皮肤”按钮 → 主题在白天/黑夜之间切换。
- **AC-002**：黑夜模式下，工作区背景/文字/边框/滚动条 → 全部为深色系且可读。
- **AC-003**：主色皮肤在白天/黑夜下都可用 → 主色点位一致可见。
- **AC-004**：`localStorage.specwave_theme` 写入并生效 → 刷新/重启后自动恢复。
- **AC-005**：终端区域在黑夜模式下保持现状 → 不要求额外改造。
- **AC-006**：白天模式视觉保持现状 → 不引入全局联动副作用。
