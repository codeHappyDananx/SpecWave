# 左栏文件树替换为 shadcn Sidebar（需求 + 验收）

## 这份文档怎么读

- 本文件先写“你最终会看到什么”和“怎么验收”，方便你直接评审。
- 最后一段是实现约束，看不懂可以直接跳过。

## 你最终会看到什么

- 左栏不再使用“自画组件”，改为基于 `shadcn/ui` Sidebar 的统一侧栏形态。
- 这次只改左栏；顶部工具条、中栏内容区、右栏终端区都不动。
- 左栏仍是：搜索结果 / SpecWave 工作区 / 项目文件。
- 点目录：展开或收起；第一次展开会去读取子目录；加载中会提示“加载中…”。
- 点文件：中栏打开文件内容；左栏高亮选中；并确保中栏可见。
- 目录读取失败（比如无权限）：节点显示“无法读取”的提示，同时保留错误信息，其他区域不受影响。
- 默认隐藏一批“噪音项”（例如 `node_modules`、`.git`、`dist`、`out`）；左栏提供一个开关用于“显示/隐藏这些被忽略项”，并且重启后仍保持上次状态。

## 需求（我要什么）

### REQ-001 组件来源可追溯

- 左栏 Sidebar 基座来自 `shadcn/ui` 的 Sidebar 开源实现。
- 通过 “shadcn MCP” 拉取 Sidebar 源码进仓库，并在 `06-规则.md` 记录：上游来源链接、版本或 commit、以及本仓库的必要改动点。

### REQ-002 左栏内容结构清晰

- 左栏包含可折叠分组，目前是：
  - 搜索结果（当全局搜索内容非空时出现）
  - SpecWave 工作区（`.specwave/workspace`）
  - 项目文件（当前打开项目目录）
- 每个分组内部是树：目录可展开/收起，文件可点击打开。

### REQ-003 目录展开、文件打开与联动

- 目录节点：
  - 点击切换展开/收起。
  - 首次展开触发懒加载：加载中给提示；加载失败给出明确提示，但不影响其他节点操作。
- 文件节点：
  - 点击后在中栏打开文件内容，并同步左栏选中态。
  - 打开文件时自动确保中栏可见（保持既有行为）。
- 联动：
  - 左栏选中态与中栏当前文件保持一致。
  - 若当前文件所在路径未展开：左栏尽量自动展开到可见；做不到时也必须保证选中态正确。

### REQ-004 读取失败（含无权限）与显隐规则

- 目录读取失败（含无权限）时：
  - 节点展示“无法读取”的提示，并保留错误信息用于排查。
  - 不允许出现整棵树卡死、白屏或崩溃。
- “显示被忽略项”的开关按钮（默认关闭）：
  - 默认隐藏一组“噪音目录/文件”（例如 `node_modules`、`.git`、`dist`、`out` 等）。
  - 打开后显示这些被忽略项；关闭后隐藏。
  - 开关状态需要持久化（LocalStorage 或等效机制）。

### REQ-005 样式与可用性

- Sidebar 与树节点交互必须符合 `SPECWAVESTYLE.MD`：Light/Flat、无阴影、反馈直接、动效快（约 200ms）。
- 本 Story 会引入 Tailwind，用来直接复用 `shadcn/ui` Sidebar 的现成样式写法。
- 除引入的 shadcn 组件外，项目自写组件仍优先使用 CSS Modules；禁止把组件样式写入全局 `packages/ui-next/src/styles.css`。
- 键盘可用性：至少支持 Tab 聚焦、Enter 触发（目录展开/文件打开）。

### REQ-006 架构边界不被破坏（给开发的硬约束）

- `packages/ui-next` 只渲染 `ViewModel`、只派发 `UIIntent`，不写业务逻辑。
- 新增交互语义时：先改 `packages/contracts`（类型/意图），再改 `store` 实现，最后改 UI 消费。
- 左栏不得直接接触 Node/Electron 能力；读目录/读文件统一走 preload API。

## 验收（怎么判做完）

### AC-001 替换完成

- 左栏文件树与分组区域由新 Sidebar 形态驱动，不再依赖旧的“自画树渲染”实现。

### AC-002 基本交互闭环

- 打开任意项目目录后：
  - 展开目录会加载并展示子节点；
  - 点击文件会在中栏打开内容，左栏高亮选中；
  - 再次点击已展开目录会收起。

### AC-003 无权限/异常不崩

- 对一个无权限目录执行展开：
  - 左栏显示“无法读取”提示与错误信息；
  - 应用其他区域仍可正常操作，不出现空白/崩溃。

### AC-004 “显示被忽略项”开关可用

- `node_modules`、`.git` 等默认被隐藏（不出现在树中）。
- 打开“显示被忽略项”开关后，这些条目可见；关闭后再次隐藏。
- 重启应用后开关状态保持一致。

### AC-005 样式口径达标

- 左栏整体与交互反馈符合 Flat/Light：无阴影、无毛玻璃，hover/active 反馈明显，动效约 200ms。
- 没有新增任何全局组件样式到 `packages/ui-next/src/styles.css`。

### AC-006 三栏边界不被破坏

- `packages/ui-next/src/panels/left` 不 import `center/right`，三栏边界不被破坏。
- 除引入的 shadcn 组件外，项目自写组件样式仍以 CSS Modules 为主；不把组件样式写进 `packages/ui-next/src/styles.css`。
