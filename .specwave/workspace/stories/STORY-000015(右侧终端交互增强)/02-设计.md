# 设计方案

> `Story`：需求条目 STORY-000015(右侧终端交互增强)
> 状态：编写中

## 架构概述

右侧终端交互由 `TerminalView`：终端视图组件 只派发 `UIIntent`：界面意图。
`store`：状态编排 在 `TERMINAL_PASTE`：终端粘贴意图 中先尝试图片落盘，再回退文本粘贴，主进程负责剪贴板读图与文件写入。
任务卡片详情由 `CenterPanel`：中栏面板 在只读视图中按条目展示，编辑态仍沿用原文。

## 组件职责

| 组件 | 职责 | 边界 |
|------|------|------|
| `packages/ui-next/src/panels/right/TerminalView.tsx`：终端视图组件 | 捕获右键与快捷键，派发 `TERMINAL_PASTE`：终端粘贴意图 与 `TERMINAL_WRITE`：终端写入意图 | 不直连 `preload`：预加载接口 |
| `packages/ui-next/src/panels/center/CenterPanel.tsx`：中栏面板 | 任务卡片详情条目化展示与编辑入口 | 仅做展示与交互采集 |
| `packages/ui-next/src/panels/center/CenterPanel.module.css`：样式表 | 任务卡片详情条目布局与层级样式 | 仅样式，无逻辑 |
| `apps/desktop/src/renderer/src/store/handlers/terminal.ts`：终端意图处理 | 文本粘贴换行归一、图片粘贴优先、粘贴防抖 | 只在 `store`：状态编排 层做副作用 |
| `apps/desktop/src/preload/index.ts`：预加载桥 | 暴露 `terminalPasteImage`：终端图片粘贴能力 | 只做桥接不编排 |
| `apps/desktop/src/main/terminal/ipc.ts`：终端 `IPC`：进程间通信 | 注册 `specwave:terminal:pasteImage`：终端图片粘贴通道 | 不依赖 `ui-next`：界面包 |
| `apps/desktop/src/main/terminal/pasteImage.ts`：图片落盘助手 | 读剪贴板图片并写入 `.terminal-paste`：终端图片目录 | 只处理文件与返回值 |

## 关键技术决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 图片粘贴来源 | 主进程 `clipboard.readImage`：剪贴板读图 | 渲染进程无权限或不稳定时也可用 |
| 图片落盘目录 | `.terminal-paste`：终端图片目录 + Windows 隐藏属性 | 避免污染项目根目录 |
| 失败回退 | 图片失败直接走文本粘贴 | 不打断现有粘贴 |
| `Shift`：换挡键 + `Enter`：回车键 | 发送 `\n`：换行符 | 满足“换行不提交”诉求 |
| 详情条目解析 | 按行拆分并识别包含 `：` 的条目 | 不改任务正文存储格式 |
| 详情编辑模式 | 编辑态继续使用原文 | 降噪展示不影响编辑体验 |
## 交互契约包（涉及接口对接时必填）

契约文件：`refs/contracts/terminal-paste-image.md`
关键口径：`TERMINAL_PASTE`：终端粘贴意图 触发时先调用 `specwave:terminal:pasteImage`：终端图片粘贴通道，失败即回退到文本粘贴。

## 风险与依赖

- 依赖 `electron`：桌面运行时 的主进程剪贴板读图能力，失败时回退文本粘贴
- `.terminal-paste`：终端图片目录 创建或隐藏失败时仍保留文本粘贴
- `.gitignore` 写入失败不影响粘贴流程
- 依赖任务正文包含 `：` 的条目行，无法识别时回退为纯文本展示
