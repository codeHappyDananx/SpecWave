# 需求文档

> Story：STORY-000017(MCP 与技能禁用展示)
> 状态：已确认（待进入设计）

## 概述

在左区新增一个常驻的竖向切换条，用来切换“工作区”和“`codex`：能力视图”；能力视图展示 `MCP`：模型上下文协议服务 与 `skills`：技能 的列表与状态，并支持动态探测与刷新。

## 你最终会看到什么

左区最左侧多一条永远存在的竖向切换条，包含 2 个图标：工作区与能力。默认仍是工作区。点“能力”后，左区主体切到一个列表页，按分组展示 `MCP` 与 `skills`，每项都有图标、名称、简要说明与“可用/不可用/检测中/未知”的状态，悬停会显示提示气泡，列表提供“刷新”来重新探测。

## 需求清单

### REQ-001 左区常驻切换条

在左区新增一个永远存在的竖向切换条，用于切换左区主体内容。

- **操作**：用户打开应用并观察左区
- **预期**：左区最左侧存在竖向切换条；包含“工作区”和“能力” 2 个图标；悬停显示 `tooltip`：提示气泡（说明图标用途）

### REQ-002 切换不影响现有左区工作区能力

“工作区”视图保持现有行为与交互不变，切换回工作区时不丢失用户的当前浏览状态（例如：展开折叠、选中项、滚动位置）。

- **操作**：用户在工作区进行浏览操作后，切到“能力”，再切回“工作区”
- **预期**：工作区视图与切换前一致；不出现跳回顶部、全折叠、丢选中等体验回退

### REQ-003 能力视图基础展示（MCP 与技能）

新增“能力”视图，展示 `codex` 环境的 `MCP` 与 `skills` 列表；列表按分组展示，且每项包含基本信息。

- **操作**：用户点击左区切换条上的“能力”图标
- **预期**：左区主体切换为能力视图；按分组展示 `MCP` 与 `skills`；每条至少展示：图标、名称、状态、简要说明；悬停提示气泡显示更完整说明

### REQ-004 MCP 状态动态探测与刷新

对 `MCP`：模型上下文协议服务 提供动态探测能力，且不要求用户改变原本的 `codex` 使用方式。

- **操作**：用户首次进入能力视图，或点击“刷新”
- **预期**：系统触发一次 `MCP` 状态探测，并更新每个 `MCP` 的状态（可用/不可用/检测中/未知）；探测过程不阻塞界面交互；探测失败时展示可理解的失败原因（脱敏后）

### REQ-005 skills 状态探测与问题提示

对 `skills`：技能 提供状态探测与问题提示，帮助快速定位“技能无法使用”的常见原因。

- **操作**：用户首次进入能力视图，或点击“刷新”
- **预期**：系统更新每个技能的状态；当技能结构不完整（例如缺少 `SKILL.md`）时，状态显示为不可用并提示原因；不会因为单个技能异常导致整个列表空白或卡死

### REQ-006 逻辑独立与敏感信息保护

能力探测与数据解析必须独立成单独模块，避免把逻辑写进现有 UI 文件中；探测过程中不得泄露敏感信息。

- **操作**：系统在能力视图中展示 `MCP` 与 `skills` 信息与探测结果
- **预期**：探测逻辑位于独立文件/模块；任何密钥/口令类配置不以明文展示（只显示键名，值打码或完全隐藏）；错误信息不包含可直接复用的凭证内容

### REQ-007 MCP 安装（从 JSON 导入，走官方命令）

能力视图提供 `MCP`：模型上下文协议服务 的安装入口，支持用户粘贴一段普通 `JSON` 并安装为 `codex`：工具名 可识别的 `MCP` 配置。

- **操作**：用户在能力视图点击“安装 MCP”，粘贴 `JSON`，确认安装
- **预期**：系统将 `JSON` 转换为 `codex` 官方配置口径，并通过官方 `CLI`：命令行界面 执行安装；安装成功后列表出现新条目并可探测状态；安装失败给出可理解原因（脱敏）

### REQ-008 skills 安装（zip 或目录/单 md）

能力视图提供 `skills`：技能 的安装入口，支持两种来源：
- `zip`：压缩包，解压后作为一个技能目录安装
- `md`：单文件或目录内的 `SKILL.md`；若选择单个 `md`，则以该文件为 `SKILL.md` 创建技能目录；若选择目录内的 `SKILL.md`，则复制该 `SKILL.md` 所在目录的全部内容安装

- **操作**：用户在能力视图点击“安装技能”，选择 `zip` 或 `md`（或包含 `SKILL.md` 的目录）
- **预期**：系统按官方技能发现机制将文件落到技能目录中；安装成功后技能列表出现新条目并显示结构可用性；安装失败给出可理解原因

## 验收口径

- **AC-001**：打开应用 → 左区左侧出现常驻竖向切换条，悬停图标出现提示气泡
- **AC-002**：在工作区展开目录并选中文件 → 切到能力再切回 → 展开/选中/滚动均保持
- **AC-003**：点击“能力” → 左区展示 `MCP` 与 `skills` 分组列表，而不是空白页
- **AC-004**：进入能力视图 → 状态先显示“检测中”，随后更新为“可用/不可用/未知”
- **AC-005**：点击“刷新” → 状态重新进入“检测中”，并在合理时间内更新
- **AC-006**：任意一项探测失败 → 仅该项显示失败原因，其他项仍可正常展示与刷新
- **AC-007**：列表展示的配置与报错信息不包含明文密钥/口令
- **AC-008**：点击“安装 MCP” → 粘贴 `JSON` → 安装成功 → `MCP` 列表出现新条目，并可刷新探测状态
- **AC-009**：点击“安装技能” → 选择 `zip` 或 `md` → 安装成功 → `skills` 列表出现新条目，且能提示结构是否完整

## 边界约束（可选）

- 不改变现有右区终端分区与交互。
- 不要求用户新增启动脚本或手工设置环境变量；能力视图应基于现有 `codex` 环境自动探测与展示。
- 探测默认不应引入长时间阻塞；需要超时与可取消策略（以设计文档为准）。
- 安装过程必须走官方口径：`MCP` 使用 `codex mcp add`；`skills` 使用官方技能目录发现机制（以文档为准）。
