# 需求文档

> Story：STORY-000011(顶部栏优化-shadcn与字体一致)  
> 状态：已确认

## 你最终会看到什么

1) 顶部栏（项目 tabs / 搜索 / 功能按钮）统一为 shadcn 风格的工具栏：控件高度、圆角、hover/focus、分组间距一致。  
2) 工作区 UI 字体统一为一套（默认 `Outfit`），但**保持当前各区域字号不变**；终端/代码区域继续使用 `JetBrains Mono`。  
3) 底部状态栏与其它 UI 的字体一致（不再出现“像另一套字体”的观感差异）。  
4) 你可以按“入口清单”自行微调各区域字号，不需要来回沟通改到满意为止。

## 背景与痛点

- 顶部栏目前由自定义组件拼装，控件风格不够统一；希望引入 shadcn 的组件体系，统一交互与视觉口径。  
- 工作区存在“字体家族不一致”的点（例如底部状态栏、右侧对话输入区出现等宽字体），导致视觉割裂。  
- 字号微调属于审美与个人偏好，容易反复沟通；更希望提供清晰入口，用户可以自己手调到满意。

## 需求列表

### REQ-001 顶部栏改为 shadcn 工具栏风格（仅上区域）

- **操作**：进入主工作区，观察顶部栏（项目 tabs / 搜索 / 功能按钮）。  
- **预期**：顶部栏控件基于 shadcn 组件实现（`Button/Input/Tooltip/Separator` 等），视觉统一、交互一致；不影响现有功能行为。

### REQ-002 工作区字体家族统一（先不改字号）

- **操作**：分别观察左栏/中栏/右栏/顶部栏/底部栏的普通 UI 文本。  
- **预期**：普通 UI 文本统一使用同一套 UI 字体（默认 `Outfit`）；现有字号保持不变（以当前版本视觉为基准）。  

### REQ-003 终端与代码区域继续使用等宽字体

- **操作**：观察右侧终端与任何代码/预格式化文本区域。  
- **预期**：终端与代码区域继续使用 `JetBrains Mono`，不受“UI 字体统一”影响。

### REQ-004 底部状态栏字体与主 UI 一致

- **操作**：观察底部状态栏“项目/文件/保存状态/主题”等文字。  
- **预期**：状态栏字体家族与其它 UI 一致（不使用等宽字体），但字号保持当前不变。

### REQ-005 提供字号/字体入口清单（给用户手动调整）

- **操作**：打开本 Story 文档中的“入口清单”。  
- **预期**：能清晰定位到各区域字号/字体设置的位置（文件 + 关键 selector/字段），用户可直接修改并立即看到效果。

## 验收口径

- **AC-001**：顶部栏只改样式不改功能：项目 tab 可切换/可关闭；“+” 行为与现在一致；搜索与按钮仍可用。  
- **AC-002**：顶部栏控件风格统一（shadcn 口径）：高度、圆角、focus ring 与其它区域一致。  
- **AC-003**：普通 UI 字体家族一致：顶部/左/中/右/底部 UI 文本不再出现“另一套字体”的观感差异。  
- **AC-004**：终端与代码区域仍为等宽字体（`JetBrains Mono`），且不受 UI 字体切换影响。  
- **AC-005**：在不主动调整字号的前提下，各区域字号保持当前版本一致（不出现“突然变大/变小”的全局变化）。  
- **AC-006**：本需求文档的“入口清单”可用于手动调整字号与字体（定位清晰、路径准确）。
