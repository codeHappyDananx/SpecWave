# 设计方案

> Story：STORY-000011(顶部栏优化-shadcn与字体一致)  
> 状态：编写中

## 架构概述

本 Story 只做两件事：

1) 顶部栏（上区域）改成“shadcn 工具栏风格”，统一控件的高度、圆角、hover/focus 与分组间距，但不改变任何功能行为。  
2) 工作区 UI 字体家族统一，先只动 `font-family`，不动任何区域的 `font-size`（字号仍以当前版本为基准）。

## 组件职责

| 组件 | 职责 | 备注/边界 |
| --- | --- | --- |
| `packages/ui-next/src/shell/TopBar.tsx` | 顶部栏的结构与交互入口 | 仅调整视觉与控件实现，不改 intent 行为 |
| `packages/ui-next/src/primitives/shadcn/button.tsx` | 顶部栏按钮基座 | 需要通过 `className` 覆盖字号，避免 `text-sm/text-base` 改动现有字号 |
| `packages/ui-next/src/primitives/shadcn/input.tsx` | 顶部栏搜索输入框基座 | 默认 `text-base` 会抬字号，使用时必须覆写为“当前字号” |
| `packages/ui-next/src/primitives/shadcn/tooltip.tsx` | 顶部栏图标按钮的悬浮提示 | 只做提示，不承载业务逻辑 |
| `packages/ui-next/src/primitives/shadcn/separator.tsx` | 顶部栏分组分隔 | 只用于视觉分组，避免“堆框线” |
| `packages/ui-next/src/styles.css` | 全局字体 tokens 与默认字体 | `--sw-font-sans` 作为 UI 字体真相源；`--sw-font-mono` 仅用于代码/终端语义区域 |

## 顶部栏（上区域）设计

### 目标形态

- 整体仍是三段布局：左（项目 tabs + 打开/新建）/ 中（全局搜索）/ 右（面板切换 + 主题）。  
- 所有可交互控件统一为 shadcn 的交互口径：一致的 focus ring、一致的 hover 反馈、一致的禁用态。  
- 避免“满屏边框/分割线”：只在分组处用少量 `Separator`，其它靠间距与背景层次区分。

### 控件映射（从现状到 shadcn）

- 项目 tabs：继续沿用 `ProjectTab` 的行为与可滚动结构；视觉对齐 shadcn 按钮（圆角、hover、active）。  
- “打开项目”：替换为 shadcn `Button`（`variant="secondary"` 或 `outline"`），并通过 `className` 保持字号不变。  
- “+ 新建页签”：替换为 shadcn `Button size="icon"`，并保留原有 `UIIntent`。  
- 搜索：替换为 shadcn `Input`（必要时继续保留前置 icon 与清空按钮），但必须用 `className` 把文字大小锁回“当前字号”。  
- 右侧图标组：用 shadcn `Button size="icon"` + `Tooltip`，active 状态用 `data-active`/class 做一层“柔和高亮”，不改现有切换逻辑。

### 字号控制策略（不改现有字号）

由于 shadcn 组件内置了 `text-base/text-sm` 等 Tailwind 字号，直接使用会改变现有视觉，因此统一采用：

- 顶部栏所有 shadcn `Button/Input` 在使用处显式追加 `className="text-[13px]"`（或与当前一致的字号类），并保持现有高度（例如 36/40px）不变。  
- 不在 `:root`/`body` 改 `font-size`，避免全局联动。

## 字体一致策略（工作区）

### 基本口径

- UI 文本（顶部栏/左栏/中栏/右栏/底部状态栏/对话输入等）统一使用 `--sw-font-sans`。  
- 代码语义区域继续使用 `--sw-font-mono`：编辑器、代码块、终端输出。

### 需要清理/回归 inherit 的位置

- `packages/ui-next/src/shell/StatusBar.module.css`：去掉 `.path` 的等宽字体指定，让它继承 UI 字体。  
- `packages/ui-next/src/shell/StatusBar.tsx`：避免在状态栏对普通文本使用 `<Badge mono>`（状态栏按 UI 字体口径）。  
- `packages/ui-next/src/primitives/PromptInput.module.css`：输入框不再强制等宽，改为继承 UI 字体（终端仍由 xterm 控制等宽）。  

### 保持等宽的区域（不动）

- `packages/ui-next/src/panels/right/TerminalView.tsx`：xterm `fontFamily` 继续用 `var(--sw-font-mono)`。  
- `packages/ui-next/src/panels/center/CenterPanel.module.css`：`.editor` / `.code` / Markdown `code` 保持等宽字体。

## 关键技术决策

1) 第一阶段不引入新的 shadcn “Tabs/NavigationMenu”组件，避免把交互重写导致行为偏差；以“shadcn 的 Button/Input/Tooltip/Separator 体系”先把顶部栏口径拉齐。  
2) “字号不变”优先级高于“完全照搬 shadcn 默认字号”；因此所有 shadcn 组件都以“调用处覆写 class”实现对齐，而不是改全局基础字号。
