# 字体来源（离线内置）

本目录内字体用于 SpecWave 桌面端离线加载（不依赖网络字体）。

## 已内置字体

- Outfit（UI 主字体）
  - 来源：Google Fonts（Outfit）
  - License：SIL Open Font License 1.1（见 `LICENSE-Outfit-OFL.txt`）
- JetBrains Mono（代码/终端字体）
  - 来源：Google Fonts（JetBrains Mono）
  - License：SIL Open Font License 1.1（见 `LICENSE-JetBrainsMono-OFL.txt`）

## 说明

- 字体文件为 `ttf`：用于原型阶段离线加载，后续进项目可按需切换为 `woff2` 或做子集化优化。
