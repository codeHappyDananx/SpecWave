# 开始执行

触发：用户说"开始"、"开始执行"、"动手"

## 前置检查

1. 确认 `03-任务.md` 存在且非空
2. 确认没有未完成的需求/设计阶段（如果 phase 不是 task，引导用户先完成前置阶段）
3. 确认用户知道这是开发阶段（不可逆的代码变更）

## 动作

1. 切换角色：需求分析师 → 开发执行者
2. 读取 `03-任务.md`
3. 按清单逐条执行
4. 每完成一项：自验证 → 标记完成 → 继续下一项
5. 全部完成后：输出任务完成报告，请求用户确认

## 执行中交互

用户说"等等" → 暂停执行，当前项标记 ⚠️ 暂停
用户说"跳过" → 跳过当前项，标记 ⏭️ 跳过
用户说"回退" → 回退到上一个 git checkpoint
用户说"重做" → 重新执行当前项

## 完成确认

所有任务完成后，必须等待用户明确确认：

```
✅ 全部任务已完成，验证通过。

摘要：
- 完成 N 项，跳过 M 项
- 编译：通过
- 影响文件：K 个

请确认：满意 / 需要调整（告诉我具体改动点）
```

用户回复"满意"或"确认" → 触发归档
用户提出调整 → 记录为新任务项，重新进入执行
