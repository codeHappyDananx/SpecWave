# 归档需求

## 触发条件

用户说"归档"/"归档需求"/"归档 STORY-xxx" 时触发。

## 前置检查

1. 确认 Story 已完成验收（所有任务已勾选，或用户明确要求归档）
2. 如果任务未全部完成，询问用户是否确认归档

## 执行步骤

> **路径说明**：技能脚本安装在 `$CODEX_HOME/skills/specwave-router/`（默认 `~/.codex/skills/specwave-router/`）。

1. 确定要归档的 Story 编号
   - 如果用户指定了编号（如 `STORY-000001`），使用该编号
   - 如果未指定，列出当前 stories 目录下的所有 Story，让用户选择

2. 调用归档工具
   ```bash
   python ~/.codex/skills/specwave-router/archive_story.py <story_id>
   ```

3. 确认归档结果
   - 成功：告知用户 Story 已归档到 `archive/` 目录
   - 失败：显示错误信息

## 归档规则

- 归档会将 Story 目录从 `stories/` 移动到 `archive/`
- 归档后的 Story 仍可查阅，但不再参与日常开发流程
- 归档操作会记录时间戳

## 示例对话

用户：归档 STORY-000001
AI：正在归档 STORY-000001...
    ✅ 已归档到 archive/STORY-000001(xxx)/
